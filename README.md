# Hélène Mac migration qualification

Owner-authorized sanitized build inputs for the legacy-to-Python migration wizard. This repository has no private Git ancestry, profiles, memory or account credentials. It is not the common official Hélène release.

The `qualification-base` asset is the immutable previously qualified native Mac application (SHA-256 `75646ae7309bd7e2a383441a0e4b3c589714b1804bbdb17950edeb1acc50dc73`). The standard macOS workflow overlays the small migration files, compiles the two Cocoa entries and exercises the served wizard with synthetic legacy data and Git edits.

Existing source licenses and notices are retained. Ad-hoc signing is not notarization; physical microphone, TCC/Gatekeeper approval and authenticated agent operation are outside this synthetic qualification. Optional heavy components are unchanged and are not rebuilt here.
